Model self-check

This page runs the browser implementation of the world model against fixtures generated by the original PyTorch code, so you can confirm for yourself that the interactive demo on the main page really is the paper's model and not an approximation of it. Everything runs locally; nothing is uploaded.

1 · Rollout parity against PyTorch

Each case is a full 40-year autoregressive rollout at a real study cell. The expected values come from the PyTorch model, stored to four decimals — so an error near 5×10-5 is the rounding floor of the fixture, not model error.
