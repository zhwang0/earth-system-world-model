What is actually being computed?

The paper's model, all 519,047 parameters, runs in this tab on that site's real climate record, seeded by five years of the Ecosystem Demography simulation. An action is a change in canopy height; the model infers everything else. Verify it against the original PyTorch.

The forest is drawn from the predicted canopy height: trees still standing match the plot left alone, a loss is trees removed, and any recovery the model predicts grows back in the gaps. Which trees go, and the props, are illustration. Actions pass through a learned decoder, so a 2 m cut lands near 2.05 m, and values are December states.

02Why interactive

Emulators made Earth models fast. But you can only watch.

An emulator replays a simulator under the climate it is given. Like early video generators, it has no input for a decision, and a digital twin needs one to answer what if.

  1. What now?

    A replica of the system as observed.

  2. What next?

    A forecast under a given climate. Emulators made this fast.

  3. What if?

    The impact of a decision. A passive emulator has no input for it.

04How it works

Emulators predict. This one takes orders.

Simulator runs contain no actions to learn from, so every observed change becomes one.

01

Actions for free

If canopy height rose 0.4 m this year, call that a +0.4 m action: supervision from data that already exists.

02

A gate, not a hint

Given an action, the gate hands height to it; given none, a dynamics head predicts growth. One model, both modes, so control costs no accuracy.

03

The rest follows

Biomass, soil carbon and the fluxes go stale after an edit, so training masks them and the model infers them from the new height.
