What is actually being computed?

The paper's model — all 519,047 parameters — runs in this tab on that site's real climate record, seeded by five years of the Ecosystem Demography simulation. An action is a change in canopy height; the model infers everything else. Verify it against the original PyTorch.

Actions pass through a learned decoder, so a 2 m cut lands near 2.05 m, and the model carries a disturbance forward rather than regrowing to the undisturbed line. Values are December states. The paper covers the rest.

Why interactive

Emulators made Earth models fast.
But you can only watch.

Machine-learning emulators reproduce expensive simulators orders of magnitude faster. Like early video generators, though, they only play back: climate in, trajectory out, with no input for a decision. A digital twin has to answer what if.

  1. What now?

    Replica. The system as observed.

  2. What next?

    Forecast under a given climate. Emulators made this fast.

  3. What if?

    Impact of a decision: log, burn, replant. A passive emulator has no input for it.

How

Emulators predict. This one takes orders.

Simulator runs contain no actions to learn from — so every observed change becomes one.

01

Actions for free

If canopy height rose 0.4 m this year, call that a +0.4 m action. Label-free supervision, from data that already exists.

02

A gate, not a hint

Given an action, the gate hands height to it. Given none, a dynamics head predicts growth. One model, both modes — so control costs no accuracy.

03

The rest follows

Edit height and the other variables go stale, so training masks them out. Biomass, soil carbon and the fluxes are inferred from the edit.
